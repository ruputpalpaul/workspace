## Expense Tracker iOS App

This repository now includes an Xcode project for a SwiftUI-based personal expense tracker. To run it:

1. Open `ExpenseTracker.xcodeproj` in Xcode 15 or newer.
2. Select the **ExpenseTracker** scheme and choose an iOS simulator (or your connected device).
3. Build and run to explore the sample data set, add new expenses, and monitor the monthly budget summary.

The project is organised with separate folders for models, view models, SwiftUI views, and shared resources to make future enhancements straightforward.
